PROJECT OVERVIEW

Purpose & Objectives

View GitHub Repository

The SFU Compass is designed to provide an interactive, accessible kiosk navigation interface for students, faculty, and visitors across the Simon Fraser University Burnaby campus. The platform integrates a graph pathfinding algorithm (Dijkstra) with physical hardware controls.

Executable Architecture Note:

The Arduino hardware ecosystem operates in tandem with a custom standalone desktop application (.exe). The executable manages high-speed COM port serial data buffering, hardware interrupts, and coordinate broadcast, powering the entire embedded routing workflow.
